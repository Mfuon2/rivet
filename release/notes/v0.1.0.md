Rivet 0.1.0 is an early preview of an MIT-licensed download manager for Windows, macOS and Linux. It includes the original desktop application, download engine, CLI, native browser helper and Chromium/Firefox extension sources.

- HTTP/HTTPS transfers with up to 16 ranges, strong-ETag resume, SHA-256 verification and a persistent local queue.
- Compact desktop workflow with menus, Lucide action icons, categories, sortable/resizable columns and light/dark themes.
- Default-browser detection, per-user native-helper registration, local extension preparation and connection checks.
- The maintainer-supplied globe/arrow logo across applications, installers and browser packages.
- Native clipboard/link support, copy confirmations, and corrected handling of oversized or incompletely framed range responses on Windows.

### Downloads and authenticity

Choose the package matching your operating system and CPU architecture. Windows has a setup EXE and ZIP; macOS has a PKG and app archive; Linux has a DEB and tarball. Linux packages are built on Ubuntu 24.04, so compatibility with older glibc versions is not promised.

The final package checksums are signed using Minisign. Download `SHA256SUMS`, `SHA256SUMS.minisig` and the matching packages. Obtain the public key from the established source repository at `release/minisign.pub`, then run:

```sh
minisign -Vm SHA256SUMS -p minisign.pub
```

Only after signature verification, check your downloaded package against its hash. The repository's `scripts/release.py verify` performs both checks and expects all packages listed in the checksum manifest. Initial signing key ID: `FACB200CA8550759`; verify the full public-key value through the official repository, rather than trusting a short ID or a key supplied only beside a download.

### Preview limitations

These packages have signed checksums, not Windows Authenticode publisher signatures or Apple Developer ID/notarization. Windows/macOS may show installation or launch warnings. The macOS app has an ad-hoc signature for local integrity checks.

Browser ZIPs are development packages, not approved store listings or Mozilla-signed XPIs. The startup screen prepares the files and native connection; load the extension in browser developer mode for now. Browser approval is not bypassed. Firefox temporary add-ons disappear after Firefox exits. Safari integration, authenticated capture, automatic download takeover, HLS/DASH video assembly and full IDM capability parity are not implemented.

Automated CI tests/builds are not a substitute for clean-machine installation, upgrade, removal and installed-browser testing. Treat this release as a preview, not a claim of production readiness. No original IDM executable, extracted proprietary component or reverse-engineering artifact is included.
