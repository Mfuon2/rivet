Desktop connection

Connect this extension to the Rivet native helper.

Setup and troubleshooting
  1. Build Rivet's native helper and package this extension.
  2. Register org.rivet.downloads for this browser and this extension's ID.
  3. Reload the extension, then check the connection.

Open Rivet → Browsers for the setup guide.

Media on this page

Enable this site to discover media and show a Download with Rivet button beside playing video or audio.

Direct media files are supported. HLS/DASH playlist assembly is planned; sending one currently saves its playlist file.
