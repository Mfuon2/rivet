# Rivet branding

The globe/orbit/arrow artwork was supplied by the project maintainer for use as Rivet’s logo. `logo.png` preserves the supplied file byte for byte. The PNG icon sizes, ICO and ICNS retain its aspect ratio and transparency; no artwork was redrawn. Lucide remains the action/file icon set.

Source SHA-256: `eafcf2b613fc9ba2533c980787af7ab51ac857717071abd267cf8b60553078d3`

Regenerate square PNGs on macOS with `swift scripts/make_brand_icons.swift`. Icons are committed, so end users and CI do not need Swift to build Rivet.
